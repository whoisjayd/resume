# Security

## Reporting a vulnerability

Please do not open a public issue for a suspected secret, credential, or privacy leak.

Contact the maintainer privately through [GitHub](https://github.com/whoisjayd) with:

- the affected file or URL;
- a description of the exposure;
- reproduction or evidence, where safe to share;
- any suggested remediation.

For ordinary documentation or build problems, open an issue instead.

## Privacy reports

The public build intentionally excludes private phone data. If you find private contact information or another unintended personal detail in tracked files, report it privately and include the exact public path.
